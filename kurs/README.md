# Block encryption utility 
# (stream encryption of large files using the GOST 28147-89 "Magma" algorithm in simple replacement mode with PKCS#7 supplement)


# Requirements:
CMake (minimum 3.15), g++


# Start utility:
Run the command in the root of project: ./start.bash
